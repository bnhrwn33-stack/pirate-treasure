# Pirate Treasure | אוצר הפיראטים

משחק פיראטים בעולם פתוח (Unity 6) · Open-world pirate game for Windows.

## הורדה / Download
Download **PirateTreasure.zip** from the [latest release](../../releases/latest), unzip it, and run `PirateTreasure.exe`.

## איך משחקים עם חברים / Playing with friends
After logging in choose **Online → Create room** and send the 5-letter code to your friends.

## מה יש בפנים
דרגות ו-XP, משימות מיוחדות ואתגרים יומיים (L), סרגל כלים ומפה קטנה, צי ספינות וקרבות ימיים, בניית יישובים, כריתת עצים, צוות וחיילים, בית עם כספת, עבודות מבעלי המסבאות, מזג אוויר משתנה בים, חיות וציפורים, ומשחק אונליין.

## חדש בגרסה 1.5 / New in v1.5
- 3 סקינים עם בדים סרוקים ב-2k, וחברים באונליין רואים אותך בדיוק כמו שאתה רואה את עצמך
- הדרגה מופיעה ליד השם באונליין, וטבלת שיאים של כל הקפטנים
- פרסים על דרגות: מטבעות ונשקים במתנה, ונשקים כבדים נפתחים לפי דרגה
- נשקייה בשוק של כל נמל, עם תמונה של כל נשק ליד השם
- ים מציאותי יותר: גלי רוח, קצף וברק של אור דרך הגלים
- אי אפשר לעבור דרך אנשים, חיות, עצים וחפצים
- קרב עם נעילה על יריב, חסימה, קומבו של שלוש מכות וסיוע בכיוון
