# Pirate Treasure | אוצר הפיראטים

משחק פיראטים בעולם פתוח (Unity 6) · Open-world pirate game for Windows.

## הורדה / Download
Download **PirateTreasure.zip** from the [latest release](../../releases/latest), unzip it, and run `PirateTreasure.exe`.

## איך משחקים עם חברים / Playing with friends
After logging in choose **Online → Create room** and send the 5-letter code to your friends.

## מה יש בפנים
צי ספינות וקרבות ימיים, בניית יישובים, כריתת עצים, צוות וחיילים, בית עם כספת, עבודות מבעלי המסבאות, מזג אוויר משתנה בים, חיות וציפורים, ומשחק אונליין.

Windows 10/11 · 64-bit · ~650 MB zipped. Settings: F4 changes graphics quality; F1 menu.
